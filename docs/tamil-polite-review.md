# Tamil text that sounds like an order — review list

Client request (25 Nov 2026): no Tamil text should sound like an order; it should feel like a kind request.

**Status:** applied in code on 25 Nov 2026 — all 117 lines below now use the gentle version; the 14 "kept" lines are unchanged. Tests updated to the new button names.

**How it was found:** every Tamil string on the public website (not the owner dashboard) was scanned for command forms — "-ங்கள்" (செய்யுங்கள், எழுதுங்கள்), "-வும்" (தொடரவும், திறக்கவும்), bare commands on buttons (செய், திற, அனுப்பு, சரிபார்) and "…வேண்டாம்" (don't). Then each one was read by hand.

**Rule for the gentle version:**

- **Buttons** use the "to do" form, like a label: மீண்டும் முயற்சிக்க, அனுப்ப, ரத்து செய்ய.
- **Optional things** use "-லாம்" (you may): தேர்வு செய்யலாம், தொடர்பு கொள்ளலாம்.
- **Required fields / errors** keep the request but add "தயவுசெய்து" (please): தயவுசெய்து உங்கள் பெயரை எழுதுங்கள்.
- **"Don't …" warnings** become "no need to …": மறுபடி பணம் செலுத்தத் தேவையில்லை.
- **Contact us** becomes a warm invitation: தயங்காமல் தொடர்பு கொள்ளலாம் (feel free to contact us).

**Found:** 117 lines to change — High 25 · Medium 71 · Low 21; plus 14 lines checked and kept (list at the end). English text is not changed.
Lines starting with "…" change only the sentence shown; the rest of the paragraph stays.

Mark any line you want different and send it back; then we update the code.
