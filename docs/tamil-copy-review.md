# Tamil text review — what changed

Goal (client): natural, everyday Tamil that everyone understands — not bookish, not machine-sounding, not Tanglish. English words are kept only where people really use them (UPI, PAN, WhatsApp, Razorpay, CSV, PDF, AutoPay, eMandate), and a few technical words carry the English in brackets, e.g. “மறைகுறியாக்கம் (encryption)”.

Style used everywhere: polite “-ங்கள்” (எழுதுங்கள், பாருங்கள்) instead of formal “-வும்” (உள்ளிடவும், சரிபார்க்கவும்); everyday words instead of heavy ones (நிலுவையில் → இன்னும் உறுதியாகவில்லை, விருப்பத்தேர்வு → விருப்பப்பட்டால், அளியுங்கள் → கொடுங்கள், “கட்டணம்” for a payment → பணம் / பணம் செலுத்துதல்). English text is unchanged.
